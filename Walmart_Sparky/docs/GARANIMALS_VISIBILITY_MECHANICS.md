# Garanimals Visibility Mechanics in Sparky

**Purpose:** How Garanimals brand interfaces with Walmart's Sparky AI system.

**Last Updated:** Mar 17, 2026

---

## The Core Correlation

### Perfect 1P Dependency
**Fundamental rule:** Garanimals visibility = f(1P product dominance)

**The relationship:**
- 100% 1P results → 40-60% Garanimals
- 80% 1P → 40% Garanimals  
- 40% 1P → 20% Garanimals
- 0% 1P → 0% Garanimals

**R² = 1.0** - Perfect correlation, no exceptions.

**Implication:** Garanimals is a proxy for 1P routing. If you see Garanimals, Sparky chose the 1P path.

## Query Performance Matrix

### High Visibility (40-60%)
- **Value queries:** "cheap", "affordable" → Triggers 1P route, Garanimals positioned as value brand
- **Generic brands:** "best kids brands" → 1P bias favors Garanimals
- **Comparative:** Direct mention forces inclusion + 1P bias

### Zero Visibility (0%)
- **Seasonal:** "back to school" → Routes to 3P specialty sellers
- **Gift/novelty:** "cute outfit for niece" → Routes to 3P personalized items
- **"Best selling" anomaly:** May trigger marketplace routing over 1P preference

### Low Visibility (20%)
- **Mixed categories:** "mix and match" → Borderline routing (40% 1P / 60% 3P)

## Optimization Strategy

### Maximize Visibility
✅ Use value terms: "cheap", "affordable", "budget"  
✅ Target generic categories: "shirts", "pants", "clothes"  
✅ Avoid seasonal context: "back to school", "halloween"  
✅ Avoid gift framing: "cute outfit for", "gift"  
✅ Test without "best selling" modifier

### Context Management
⚠️ Conversation context is sticky - gift/novelty routing persists across follow-ups  
⚠️ May need new conversation to escape 3P routing  
⚠️ "Cute" appears to trigger specialty routing even without explicit gift context
