# TikTok Shop CLI — API Map

## Site Profile
- **Type**: No-auth + Read-only SPA
- **Base URL**: https://shop.tiktok.com
- **Protocol**: REST (custom SSR + JSON API)
- **Auth**: None (public product search)
- **HTTP Client**: httpx

## Data Extraction Strategy

### Initial Search (Page 1)
GET `https://shop.tiktok.com/us/s?q=<keyword>`

Parse `<script type="application/json" id="__MODERN_ROUTER_DATA__">` from HTML.

Navigate: `loaderData["(region)/(route_page_name)/page"]["page_config"]["components_map"]`

Find component with `component_name == "feed_list_search_word"`:
- `component_data.products[]` — first 20-30 products (SSR)
- `component_data.load_more_params` — `{offset, page_token, api_source}` for pagination

### Product Pagination (Pages 2+)
POST `https://shop.tiktok.com/api/shop/brandy_desktop/s/product_list`

Request body (JSON):
```json
{
  "component_info": "{\"component_type\":\"feed_list\",\"component_name\":\"feed_list_search_word\",\"fe_config\":{\"is_main_feed\":true,\"is_fmp_significant\":true,\"show_structure_data\":false,\"show_empty_page\":true,\"empty_text\":{\"title\":\"No results found\",\"sub_title\":\"Try another search\"},\"title\":\"Results for {keyword}\",\"data_source\":{\"type\":\"search_word\",\"storage_global_product_info\":true,\"params\":{\"count\":30,\"clamp\":true}}}}",
  "load_more_params": "{\"offset\":30,\"page_token\":\"<token>\",\"api_source\":2,\"search_word\":\"<query>\",\"seller_id\":\"\",\"filters\":[{\"filter_option_id\":\"<sort_filter>\"}],\"exclude_product_ids\":[]}"
}
```

Response: `{code, message, data: {products[], has_more, load_more_params, filter_sections}}`

### Search Suggestions (Implemented via SSR)
The `POST /api/shop/brandy_desktop/s/get_suggest_words` endpoint exists but requires the
browser-generated `X-Tts-Oec-Bsid` session token — without it, it returns `{code: 10000}`
with no data. Instead, the CLI extracts `related_link_search_words` component data from the
SSR HTML (same GET request used for search). This returns related search terms.

SSR path: `loaderData["(region)/(route_page_name)/page"]["page_config"]["components_map"]`
→ find component with `component_name == "related_link_search_words"`
→ `component_data.related_links[].name`

## Product Data Model

```python
Product:
  product_id: str
  title: str
  price: str              # e.g. "29.99"
  currency: str           # e.g. "USD"
  price_prefix: str       # e.g. "From" or ""
  rating: float           # e.g. 4.7
  review_count: str       # e.g. "35137"
  sold_count: int         # e.g. 510820
  shop_name: str          # e.g. "medicube US Store"
  seller_id: str
  image_url: str          # First image URL
  seo_url: str            # e.g. "/us/pdp/slug/id"
  brand_name: str | None
```

## Sort Filter IDs

| CLI option | filter_option_id |
|-----------|-----------------|
| best (default) | (no filter) |
| price-asc | ecom_price\|ASC |
| price-desc | ecom_price\|DESC |
| newest | ecom_publish_time |
| best-sellers | ecom_sold_count |

## Price Filter IDs

| Range | filter_option_id |
|-------|-----------------|
| Under $30 | ecom_max_price\|30 |
| $30-$40 | ecom_price_stat\|30,40 |
| $40-$100 | ecom_price_stat\|40,100 |
| Over $100 | ecom_low_price\|100 |

## CLI Command Structure

```
cli-web-tiktokshop [--json]
  search query <query>     Search for products
    --sort [best|price-asc|price-desc|newest|best-sellers]
    --price-range [under-30|30-40|40-100|over-100]
    --limit INT            Max results (default 30, max ~300)
    --page INT             Page number (default 1)
  search suggest <query>   Get related search terms (from SSR HTML)
```

## Notes
- The `X-Tts-Oec-Bsid` URL param in API calls is an analytics session token generated by browser JS. It is NOT required for auth — requests work without it.
- Product images are on `ttcdn-us.com` CDN.
- Service worker is active on the site — CLI uses plain httpx (no Playwright needed).
- Direct navigation to `/pdp/` and `/c/` pages triggers captcha — search page only.
